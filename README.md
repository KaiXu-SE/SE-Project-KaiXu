# KaiXu（开序）

KaiXu 是面向高校学生的课程学习计划与课程项目协作系统。它以“课程”和“项目”为基本工作区，把分散在教学平台、课程群和口头通知里的任务、日程和学习资料收进同一个入口，帮助学生把截止日期落到具体执行时间，并在小组项目中共享目标的同时保住个人排期隐私。

## 要解决的实际问题

1. **通知太散**：作业和考试安排分布在 Canvas、微信/QQ 群和老师口头提醒里，容易漏记或记错截止时间。
2. **只记截止、没排时间**：普通待办只提醒哪天交，临近期末多门课程项目和复习撞在一起时，很难提前安排每天做什么。
3. **资料难找且会过期**：课件、作业要求和小组文件散落在本地文件夹和群聊里，微信群文件过期后还要反复找人重发。
4. **小组进度和个人时间脱节**：小组作业需要同步分工和截止时间，但每个人的课表和空余时间不同，成员也不想把私人时间安排公开给全组。

## 核心功能范围

本项目按“先个人可用、再小组协作、最后扩展接入”的顺序分增量交付：

- **课程与项目工作区**：按课程或项目分类存放任务、日程和资料；支持把项目关联到某门课程，也允许记录不属于任何课程的个人事项，支持导入标准格式学期课表，预览确认后同时建立课程工作区与对应上课固定事件。
- **多来源任务收集**：核心支持手动录入、授权 Canvas 作业只读拉取，扩展支持课程群消息结合 AI 辅助提取任务与日程；所有外部和 AI 生成的候选项都先预览核对，经用户确认后再正式入库。
- **截止时间与执行时段分开管理**：任务的截止日期和实际动手做的“工作时段”分开记录；日历统一展示上课、考试、会议等固定事件和个人工作时段，并在时间重叠或超出截止日期时给出提示。
- **资料按任务关联**：在工作区保存链接、简短笔记或文件附件，并关联到具体任务，打开任务就能直接拿到对应资料。
- **小组项目协作与隐私隔离**：项目所有者可以邀请成员加入，全组共享任务、负责人、状态、阻碍说明、共同事件和项目资料；每位成员为共享任务安排的个人工作时段始终仅本人可见。

当前阶段仅确定业务范围和需求，具体客户端形态与技术实现方案将在概要设计阶段评审确定。
