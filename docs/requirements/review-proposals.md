# 需求评审方案

本页供 [Issue #11](https://github.com/KaiXu-SE/SE-Project-KaiXu/issues/11) 评审。交付增量、输入规范和候选指标由组内确认后纳入验收。

## Android 快速录入

建议纳入 **M2**。M2 已规划账号同步和任务状态更新。快录复用同一套账号权限、任务保存和重试规则，表单只需一个字段。现行 M2 验收范围见[里程碑](https://github.com/KaiXu-SE/SE-Project-KaiXu/milestone/2)，确认快录排期后，同步 #11、章程、SRS、用户故事、追溯矩阵和里程碑。

- **正常流程** 已登录且联网的学生从 Android 首页打开快录，填标题并保存。去掉首尾空白后标题应非空。保存成功后创建一条当前账号的独立个人任务，状态为待办，工作区、截止日期和估时可留空。Windows 端以同一账号刷新能看到该任务。
- **失败与重试** 空白标题在提交前提示修正。连接中断或会话失效时，界面以服务端确认结果为准，用户恢复同一账号及联网状态后手动重试。同一次保存的连点及响应丢失后的重试只产生一条任务。可重试的标题仅在当前账号的录入会话中保留。

| 验收场景 | 通过条件 |
| --- | --- |
| 从首页仅填标题后保存 | 不含打字的主要操作最多 4 次。当前账号两端看到同一条待办任务，另一账号无法打开它。 |
| 提交空白标题 | 界面提示填写标题，正式任务数保持原值。 |
| 保存按钮连点，或服务端保存后响应丢失并手动重试 | 最终只产生一条任务，界面在收到服务端确认后才显示保存成功。 |
| 会话已失效或请求发送前断网 | 用户收到连接或登录提示，正式任务数保持原值。恢复同一账号联网之后可手动提交。 |

对应 [UC-14](srs.md#uc-14-处理-android-在线日常操作)、[FR-T01](srs.md#fr-t01)、[NFR-R03](srs.md#nfr-r03) 和 [NFR-U01](srs.md#nfr-u01)。

## 标准学期课表

建议采用 **UTF-8 CSV**，可带 BOM。首行为下表字段名，每个文件对应一个学期，每一行描述同一日期内的一次上课。源课表使用周次、单双周或节次时，先按学校确认的学期日历和节次表换成实际日期和钟点，再生成 CSV。

| 必填列 | 含义与校验 | 示例 |
| --- | --- | --- |
| `term_id` | 稳定的学期标识，同一文件内一致。 | `2026-fall` |
| `course_id` | 学期内稳定的教学班标识。同名不同班使用不同标识。 | `DEMO-SE-A` |
| `course_name` | 展示名称。同一学期及教学班在同一文件里使用一致的名称。 | 示例软件工程 |
| `date` | 实际上课日期，采用 `YYYY-MM-DD`。 | `2026-12-01` |
| `start_time` | 同一天的开始时刻，采用 24 小时制 `HH:mm`。 | `08:00` |
| `end_time` | 同一天的结束时刻，格式同上，且晚于开始。 | `09:40` |

导入时按课表的来源时区 `Asia/Shanghai` 解析日期与起止时刻。导入后的固定事件按 [BR13](srs.md#业务规则) 转换到用户时区显示。

在当前数据空间内，用 `(term_id, course_id)` 匹配课程工作区，用 `(term_id, course_id, date, start_time, end_time)` 匹配同一上课事件。首尾空白去除后比较标识，区分大小写。源表没有教学班标识时，由制表方为同一教学班提供固定编号。课程名用于展示，已按标识匹配但名称有差异时在预览中提示。

预览列出拟新建、已匹配、重复和错误的记录。相同事件在同一文件重复或已导入时都只保留一条。缺少必填字段、日期或时刻无效、结束不晚于开始、学期混用或一教学班在同一文件出现冲突名称时，标明行号和原因，修正后再确认。用户确认的课程和事件整批生效，写入失败按 [UC-19](srs.md#uc-19-预览并导入标准课表) 保留原数据和可重试的预览。

[课表样例 CSV](examples/timetable-sample.csv)为合成数据，除表头外共四条记录，其中两班同名，一条课次重复。用于复测去重，正式定稿前再与实际脱敏课表核对字段来源。

| 验收场景 | 通过条件 |
| --- | --- |
| 空的数据空间中预览样例 | 预览显示 2 门课程、3 次上课和 1 行重复，正式课程和事件仍为 0。 |
| 确认样例后再原样导入一次 | 首次生成 2 个课程工作区和 3 个固定事件，第二次的总数仍为 2 和 3。同名不同班各有独立工作区。 |
| 在用户时区为 `Asia/Tokyo` 时查看并原样重复导入课表 | 样例源文件中的 `08:00` 课次在日程显示为 `09:00`，重复导入匹配同一课次。 |
| 把任意一行的结束时刻改成与开始相同 | 预览标出错误行，正式数据保持提交前的内容。 |
| 首次确认样例时模拟写入事件失败，再重试 | 失败时没有任何课程或事件部分入库，重试成功后总数为 2 个课程工作区和 3 个固定事件。 |

对应 [FR-I08](srs.md#fr-i08)、[FR-S11](srs.md#fr-s11) 和 [NFR-R02](srs.md#nfr-r02)。

| AI 提取预算及输入输出限制 | 每次提取不超过 0.10 元，最多重试一次，输入及输出分别不超过 1,000 和 500 token。 | [NFR-A04](srs.md#nfr-a04) |
