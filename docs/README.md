# 文档目录索引

本目录按软件工程课程阶段存放项目文档与过程记录。

## 目录结构

| 路径 | 存放内容 | 当前状态 |
| --- | --- | --- |
| `docs/governance/` | 团队分工与协作制度 | 已建立 |
| `docs/requirements/` | 调研计划、访谈记录、竞品分析、调研报告、用户故事、SRS 与追溯矩阵 | 已建立（调研与用户故事初稿已交付；SRS 与追溯矩阵后续建设） |
| `docs/models/` | 需求分析模型与图源文件（用例图、类图、状态图、顺序图等） | 第 4–5 课建设 |
| `docs/design/` | 概要设计、详细设计、API 契约与架构决策记录（ADR） | 第 6–7 课建设 |
| `docs/testing/` | 测试计划、测试用例与测试报告 | 编码与迭代阶段建设 |
| `docs/iterations/` | 迭代计划、回顾报告与会议/课堂反馈记录 | 迭代阶段建设 |
| `docs/ai/` | AI 使用台账与期末《AI 使用报告》 | 持续维护 |
